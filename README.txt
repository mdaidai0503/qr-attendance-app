QR出退勤アプリ v2.3（端末登録方式・社員番号/PIN入力なし）
========================================================

【v2.3の使い方】
1. 管理者が「インストール」から従業員用インストールQRを表示
2. 従業員は自分のiPhoneで開き、ホーム画面に追加
3. 管理者 → 従業員管理 → 対象従業員 →「端末登録QR」
4. 従業員本人のiPhoneカメラで端末登録QRを1回読み取る
5. 以後は会社入口の「固定打刻QR」を読み取るだけ
   ・未出勤なら自動で出勤
   ・出勤済みなら自動で退勤
   ・社員番号入力なし
   ・PIN入力なし
   ・打刻ボタン操作なし

【安全性】
・アプリ自体は誰でも開けます。
・未登録端末は固定QRを読んでも打刻できません。
・端末登録QRは15分間・1回だけ有効です。
・管理者は従業員ごとに登録端末を確認し、紛失時は「端末解除」できます。
・誤って固定QRを連続で読む二重打刻を防ぐため、60秒以内の再打刻を拒否します。

【重要：iPhoneのブラウザ】
端末登録は、固定QRを読み取るときに使うブラウザに保存されます。
iPhoneカメラからQRを開くブラウザを途中で変更した場合は、端末登録をやり直してください。
